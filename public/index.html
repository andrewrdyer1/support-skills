A hands-on course

Support engineering skills

SQL, HTML and CSS, HTTP and APIs, debugging a real incident, and Python scripts with tests: the technical side of support engineer and CX operations roles, learned by doing the job.

You've just joined support at Paperkite, a made-up invoicing app for small businesses. It runs entirely on your Mac: a real Postgres database with about 240 customer accounts, a real API you can call with curl, real logs, and one real bug waiting in Lesson 6. Every lesson starts with a customer ticket and ends with you answering it.

    How it works

    Grey boxes with a Run or Send button are live. Edit anything. You can't break the data: your database access is read-only, and the API runs in test mode. Exercises check your answer and remember your progress in this browser.

    To start the course again later: open Terminal, cd ~/Developer/support-skills, run npm start, and visit localhost:4747. To put the data back the way it started, run npm run reset.
